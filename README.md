# Hyllytarkastus

Puhelimessa toimiva hyllytarkastuksen havaintotyökalu. Sovellus tallentaa havainnot käyttäjän omalle laitteelle eikä edellytä kirjautumista.

## Julkaisu

GitHub Pages julkaisee tämän repositorion päähaaran sisällön. Päivitys tehdään korvaamalla sovellustiedostot ja tallentamalla muutos `main`-haaraan.
